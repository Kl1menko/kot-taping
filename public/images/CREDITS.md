# Зображення сайту

Усі знімки з тейпуванням — **власні роботи студії Kotova Taping**, передані
майстринею (тека `photo tapes`). Раніше на картках послуг стояли стокові фото з
Pexels; їх замінено, і посилань на сток на сайті більше немає.

## Картки послуг — `services/`

Файл береться за slug категорії: `/images/services/{category}.jpg`.
Формат 800×1000 (4:5) під медіа-блок картки.

| Файл | Категорія | Що на знімку |
|---|---|---|
| `muscle.jpg` | М'язеві корекції | Х-аплікація на плечах (постава) |
| `neuro.jpg` | Неврологічні | Сітчаста аплікація на шиї та надпліччі |
| `lymph-body.jpg` | Лімфодренаж тіла | Перехресне тейпування живота |
| `lymph-face.jpg` | Лімфодренаж обличчя | Віялова аплікація на щоці |
| `face-modeling.jpg` | Моделювання обличчя | Тейп навколо губ (кисетні зморшки) |
| `sets.jpg` | Набори | Віялові смуги на сідницях |

Усі послуги однієї категорії показують те саме фото — окремого знімка на кожну
послугу зараз немає.

## Набори для самотейпування — `kits/`

Файл береться за slug набору: `/images/kits/{slug}.jpg`.
Формат 960×600 (16:10) під плитку картки.

| Файл | Набір |
|---|---|
| `neck.jpg` | Шия |
| `face-full.jpg` | Обличчя повністю |
| `face-forehead.jpg` | Чоло |
| `face-mouth.jpg` | Рот |
| `face-cheeks.jpg` | Щоки |

## Галерея — `gallery/`

`sample-1…7.jpg`, 800×1000. Порядок і підписи — у `src/lib/gallery.ts`;
міняючи файли, поправте там `alt` і `caption`, інакше підпис розійдеться з фото.

## Прев'ю для соцмереж — `og-bg.jpg`

Градієнтне тло 1200×630 для `src/app/opengraph-image.tsx`. Вбудовується в
картинку як data-URI під час збірки, тож замінюйте файл із тим самим іменем.

## Як замінити

Код правити не треба — покладіть новий файл із тим самим іменем. Тримайтеся
пропорцій (4:5 для послуг і галереї, 16:10 для наборів), інакше `object-cover`
обріже знімок.

## Згода на публікацію

Це фото реальних клієнток. Перш ніж додавати нові, переконайтеся, що згода на
публікацію отримана — те саме стосується секції «Результати».
